# 🌾 Feature Selection for CME Wheat Futures Forecasting

**Weekly forecasting of CME Wheat Futures (ZW) using market factors and systematic feature selection.**

> This project exhaustively compares 20+ feature selection methods combined with Lasso regression to identify the most robust and accurate configuration for forecasting CME wheat futures.

---

## 🎯 Project Goal

The main objective is to **identify the best feature selection configuration** for building a Lasso regression model on CME wheat futures data, balancing predictive accuracy, feature stability, and computational efficiency.

The pipeline covers:
- 🧪 Feature engineering (12 analytical categories, ~3,200+ features)
- 🔄 Rolling-window cross-validation (2, 7, All Years training depths)
- 🧠 Comprehensive feature selection methods (filter, wrapper, embedded, metaheuristic, dimensionality reduction, causal)
- 📊 Multi-dimensional performance evaluation (error, directional, stability, and diversity metrics)
- 🎨 Publication-ready visualizations

## 🛠 Feature Engineering

Features are constructed **before** cross-validation to cover the whole dataset. Twelve analytical categories are generated by `generate_all_features()`:

| # | Category | What it captures |
| :--- | :--- | :--- |
| 1 | 🧠 **Memory (Lags)** | `lag_1, 2, 3, 4, 12, 52` — inertia and annual seasonality |
| 2 | 🚀 **Momentum** | `diff_1, 4, 52`, acceleration, smoothed momentum |
| 3 | ⚖️ **Relative Strength** | `pr/e`, `pr/c`, `pr/$`, `pr/b` — price cleaned from market noise |
| 4 | 📊 **Channels & Levels** | Relative position, distance to SMA, SMA slope (12/52/104w) |
| 5 | 📉 **Volatility** | Spread, Z-score, annualized vol, vol % change |
| 6 | 🩺 **Trend Health** | Up-weeks count, Efficiency Ratio |
| 7 | 🔗 **Cross-Asset Correlations** | Rolling correlation (13w) between price and factors |
| 8 | 💥 **Distribution Tails** | Weeks since max, outlier flag (|Z| > 2.5) |
| 9 | 🌀 **Fractality** | Fractal dimension / Hurst proxy |
| 10 | 📆 **Seasonality** | Expanding mean by month (no leakage) |
| 11 | 🎚️ **Spread Dynamics** | Rate of convergence with benchmarks |
| 12 | 📏 **Stationarity** | Multi-period log returns (1w, 2w, 4w, 12w, 52w) |

Additional synergy features: Volatility × Volume interaction, Momentum spreads, Historical channel breakouts, Cumulative position flow (COT), Logistics cost pressure.

## 🔄 Methodology

### Rolling-window validation
- **Start period:** week 264 (~5 years of history before first forecast)
- **Learning step:** 20 weeks
- **Training depths:** 2 years, 7 years, All available history
- **Horizon:** next-week log return → inverse-transformed to price levels

### Pipeline per window

```text
Slice dataset by period
        ↓
Feature selection method (with specific parameter/top-N features)
        ↓
StandardScaler (fit on train only — no leakage)
        ↓
LassoCV (TimeSeriesSplit, 150 alphas, eps=1e-15)
        ↓
Inverse-transform log-returns → price levels
        ↓
Compute multi-dimensional metrics & store results
```

## 🧠 Feature Selection Methods

### ✅ Implemented & Evaluated

| Method | Marker | Type | Key Characteristics |
| :--- | :--- | :--- | :--- |
| **Baseline Lasso** | `las` | Embedded | No pre-selection, L1 regularization only |
| **Pearson Correlation** | `las_corr_p` | Filter | Threshold-based linear correlation filtering |
| **Spearman Correlation** | `las_corr_S` | Filter | Threshold-based rank correlation filtering |
| **Mutual Information** | `las_mu_inf` | Filter | Non-linear dependency filtering |
| **VIF** | `las_VIF` | Filter | Multicollinearity reduction |
| **Boruta** | `las_BOR` | Wrapper | Random Forest based all-relevant feature selection |
| **RFE / RFECV** | `las_RFECV`, `las_RFECV_RF` | Wrapper | Recursive elimination with Linear/RF estimators |
| **Sequential Feature Selection** | `las_SFS` | Wrapper | Greedy forward/backward selection |
| **XGBoost Importance** | `las_XGB` | Embedded/Filter | Tree-based feature importance ranking |
| **SHAP Values** | `las_SHAP` | Wrapper/Filter | Game-theoretic feature attribution |
| **Permutation Importance** | `las_PERM` | Wrapper | Model-agnostic performance-drop evaluation |
| **Stability Selection** | `las_STB` | Metaheuristic | Subsampling-based robust feature selection |
| **PCA Variants** | `las_PCA`, `las_BPCA`, `las_PCAL` | Dim. Reduction | Linear, Bayesian, and Local principal component analysis |
| **PCMCI** | `las_PCMCI` | Causal | Causal discovery and time-series dependency |
| **Advanced Heuristics** | `las_GRP`, `las_CYC`, `las_PARA`, `las_RLF` | Hybrid | Grouped, cyclical, and custom heuristic selectors |

## 📈 Evaluation Metrics

For each rolling window and each method, the pipeline computes a **Composite Score** balancing four pillars:

1. **Performance**:
   - **MAPE** — Mean Absolute Percentage Error on price levels
   - **Directional Accuracy (DA)** — % of correctly predicted up/down moves (`Trend_Accuracy_Pct`)
2. **Stability**:
   - **R² Stability Gap** — Overfitting indicator (Train vs Test R² difference)
   - **Composition Stability (Jaccard)** — Similarity of selected feature sets between consecutive rolling windows
3. **Diversity**:
   - **Shannon Entropy** — Frequency distribution of feature selection
   - **Avg Internal Correlation** — Redundancy metric of the selected subset
4. **Efficiency**:
   - **Execution Time** — Speed comparison between methods (`Time_perf`)

## 🏆 Key Results & Insights

Based on the comprehensive evaluation across rolling windows, the top configurations by predictive performance are:

| Rank | Method | Training Depth | Key Parameters | Test MAPE | Directional Accuracy |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 🥇 1 | `las_XGB` | All Years | Top 50 features | **2.44%** | **64.2%** |
| 🥈 2 | `las_corr_p` | All Years | Top 2-7 features | 2.49% | 60.1% |
| 🥉 3 | `las_corr_S` | All Years | Top 2-7 features | 2.49% | 60.1% |
| 4 | `las_XGB` | All Years | Top 30 features | 2.45% | 62.4% |
| 5 | `las_SFS` | All Years | Top 10-50 features | 2.50% | 59.2% |

> *(Note: This table highlights the top predictive metrics for brevity. The full evaluation is based on a **Composite Score** balancing сriteria, including R² Stability Gap, Feature Diversity (Shannon Entropy), Internal Correlation, and Execution Time. Full results are available in `results/evaluation_summary.xlsx`).*

**Key Takeaways:**
- **Tree-based importance (`las_XGB`)** delivers the best raw predictive performance (lowest MAPE, highest Directional Accuracy).
- **Simple filter methods (`las_corr_p`, `las_corr_S`)** with "All Years" training depth provide exceptional feature stability (validated by advanced stability metrics in the full dataset) while maintaining highly competitive accuracy, making them ideal for robust, production-ready pipelines.
- **Sequential Feature Selection (`las_SFS`)** achieves the highest composition stability across rolling windows, proving that greedy selection excels at feature consistency, albeit with a slight trade-off in raw MAPE.
- The multi-criteria **Composite Score** successfully balances trade-offs: methods with extreme speed or extreme stability but poor accuracy naturally fall in the overall ranking.
